# 普通节点标题编辑

生产入口：`index.html` 先加载 `core.js` / `ui.js`，`app.js` 安装控制器并在节点创建、选择渲染、外壳移除、历史撤销和显式保存时接线。只处理 `image/video/audio/text/world`，并尊重 `titleEditable: false`；分组、片场、时间线及堆叠节点继续使用各自的标题实现。

未选中的节点绑定只复用原标题 span，不创建隐藏编辑 DOM。首次选中才建立输入、测量 span 和容器，后续切选复用同一控件和事件。5000 节点的窄检查确认首次未选中绑定新增编辑 DOM 为 0；选中一个节点新增 3 个元素，重复切选与 sync 不再新增。

选中节点后标题变成原生文本输入，不抢焦点；未选中时显示带省略号的 span。输入有 1000ms 防抖。Enter、正常失焦、取消选择、后续图修改或显式保存立即提交非空草稿。空白标题恢复当前标题，非空标题保留输入中的空格。Enter/Escape 完成时，输入仍持有焦点且节点身份有效才把焦点归还选中节点，让随后画布撤销/重做可用；外部控件已获得焦点则不抢回。Escape 取消**尚未提交**的草稿；已经防抖提交的标题通过画布撤销恢复。

中文 composition 期间不提交、不处理 Enter/Escape。失焦或取消选择时仍在组合输入的草稿取消；显式保存/项目导航遇到组合输入则返回“节点标题仍在输入，请完成输入后保存”。真实输入法结束顺序仍需实机验收。标题输入阻止拖动、滚轮、预览及画布键盘快捷键冒泡；原生文字选区、复制粘贴和输入内撤销保持可用。

提交前核对项目 ID、节点对象、当前外壳对象和标题基线；ID 相同但对象替换不具有提交资格。撤销/重做先取消草稿，外壳移除清理定时器。其他图修改在创建历史快照前先提交标题，因此普通内容重建保留刚输入的标题。保存经过现有 `remember()` / `persist()`，继续使用原存储错误、配额及版本冲突提示。读取未完成或失败时输入禁用；待提交草稿使用页面关闭保护。

字体沿用官方 `WY(12,60)` 对应的 `max(12,min(12/scale,60))` 世界字号。现有外壳用逆缩放定位，因此 CSS 使用对应屏幕字号 `clamp(12*scale,12,60*scale)`，保留已有标题宽度/渲染性能接线。

## 来源与限制

- `reference/vendor-pkg-canvas-CvuTKiTt.js` 的 `YIe`：选中且 `titleEditable !== false` 使用 `KIe`，否则 `qIe`。
- `KIe`：无边框透明原生输入，`nowheel nodrag`，测量 span 决定输入宽度，非空 1000ms 防抖。
- `qIe`：未选中标题截断。
- `EIe` / `WY` / `$Ie=12, WIe=60`：字号上下限与缩放响应。
- 主 Agent 已在官方页面点击视频节点并看到 AX text field `Video`。本模块没有修改或输入官方项目。

本地增加了生命周期和空白标题保护。Enter、Escape、IME 和存储保护是本地明确行为，不能据此宣称官方这些状态的交互与视觉已经全部一致。

```sh
node --test tests/canvas-node-titles.test.cjs tests/canvas-app-persistence.test.cjs tests/canvas-shell-invalidation.test.cjs tests/canvas-keyboard-ownership.test.cjs

```

生产入口 QA：`http://localhost:4195/src/features/canvas-node-titles/qa/production.html`。先点“创建独立验收画布”，再点“运行生产入口检查”。QA 页面在同源 iframe 加载真实 `/` 入口，创建随机 ID 项目，仅保存固定本地节点，不执行 AI 生成。生成的新 QA 项目保留以供刷新与实机复验。

自动检查覆盖五种普通节点的选中/未选中、真实生产输入事件、1 秒防抖、模拟 composition、输入手势拦截、Enter/Escape/空标题、内容重建、历史撤销/重做、导航前保存和刷新恢复。它使用合成事件，不能替代真实鼠标、输入法或屏幕验收。

CUA 实机复验步骤：

1. 打开 QA 页并创建项目；点击“打开该生产画布”。点击视频节点正文，确认 AX 出现“节点标题”原生输入；点空白处后恢复 span。
2. 点击标题输入，拖选文字、双击选择、滚轮/捏合、输入数字 `0` 和空格，确认节点/画布未移动、未触发预览或重置；正文仍可拖节点。
3. 用真实中文输入法输入标题，候选未确认前等待超过 1 秒不保存；确认候选后 Enter/失焦保存。再次输入草稿按 Escape，恢复当前已提交标题。
4. 清空标题后失焦，恢复原名；输入长中文/英文标题，在 15%、20%、70%、100%、200% 缩放下检查字体、截断、焦点、正文和节点工具栏布局。
5. 标题保存后点击空白处再执行 ⌘Z/⇧⌘Z；标题内的 ⌘Z 使用浏览器原生输入撤销。输入未提交草稿后调用/触发画布撤销，旧定时器不得重新写回。
6. 新输入标题立即点击保存或切换画布，再回到当前画布并刷新；验证两个画布各自标题。中文仍在组合输入时保存/导航应停止并保留当前页面。
7. 检查现有分组、片场和剪辑时间线标题各自可编辑，普通节点输入没有接管这些 DOM。存储失败/冲突应继续由原存储提示报告。
