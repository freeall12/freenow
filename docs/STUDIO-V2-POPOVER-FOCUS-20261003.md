# 3D 片场 2.0 浮层焦点增量

官方依据仍为 `reference/studio-v2.md` 指向的同版发布包与采集：`studio-v2-import-source.json` 使用非模态 `role="dialog"` 添加模型浮层；`studio-v2-page-readable.js` 的光照控件使用相同的 Popover 组件；`vendor-libs-DqoAc28N.js` 的 `I1r/QJi` 确认 FocusOutside 监听 `focusin`。此次保留已有布局、文字和图标。

已实现：

- 导入、帮助、光照和更多浮层在键盘焦点移到外部后关闭，外部目标保留焦点；返回触发按钮或在浮层内部移动焦点不会误关闭。
- Escape 与浮层内完成动作恢复触发按钮焦点。光照打开后聚焦第一条滑杆，更多菜单聚焦第一个操作。
- 导入检查、补充资源与保存状态重建控件时，按原控件标签恢复焦点；所有控件在保存中禁用时聚焦浮层本身。异步检查不会夺回已经移到外部的焦点。
- 保留原有“模型正在添加并保存”关闭保护，释放浮层时清理焦点监听。
- 成功添加和已应用但保存失败时，显式恢复本次导入的触发按钮，仅在原浮层仍为当前浮层时生效。首个物体添加后空态入口隐藏或卸载，改为聚焦同一片场工具栏的“添加模型”；该回退仅用于导入浮层主动完成，外部点击关闭仍保留外部焦点。

最新受影响检查：`node --test tests/studio-v2-popover-focus.test.cjs` 7/7 通过；`ui.mjs` 与 `popover-focus.mjs` 语法通过。DOM 回归覆盖焦点进出、检查时控件替换、保存保护、销毁时待处理检查、后台检查不夺焦点、鼠标失焦到 BODY 时保留待点击按钮、空态入口隐藏或卸载时回退到工具栏。

另已运行 `node --test tests/studio-v2-import-focus.test.cjs` 1/1 通过，执行实际 `add` 回调，覆盖基础图形、模型导入、保存失败及异步结束前浮层更换。`focusin` 改动依据官方契约与最小复现；早期 CUA 点击受 QA 检查器遮挡，不作为故障根因证据。

主任务新鲜浏览器验收：更多打开后聚焦首个操作，Escape 返回触发按钮，Tab 进入外部控件后关闭，光照打开后聚焦首条滑杆。收起 QA 检查器后，空片场导入球体实际得到 objects=1/revision=1 并保存；再从工具栏添加立方体，实际 objects=2/revision=2，焦点回到“添加模型”。首次添加时空态入口不可见造成焦点停在 BODY，已补上述工具栏回退；最终代码重载后再次从空态导入球体，实际焦点回到工具栏“添加模型”。本机截图：`/tmp/freenow-studio-focus-20261003.png`。

剩余浏览器验收步骤：导入缺失资源夹具并补充资源时的浮层与焦点。本轮不宣称所有 Radix 边缘行为或全部片场已完成。
