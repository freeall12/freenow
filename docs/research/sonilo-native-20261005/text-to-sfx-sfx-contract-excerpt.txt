Generate keys at the API Keys page and pass them in the Authorization header on every request. Keep keys server-side, for example in SONILO_API_KEY. Authorization : Bearer sk_your_api_key Store the key server-side, commonly as SONILO_API_KEY . A 401 means the key is missing, invalid, or revoked. A 403 means the key is valid but the account does not have access to that endpoint or workspace. Body Parameters prompt string required Text prompt describing the sound effect to generate. 1-2000 characters. duration number Desired duration of the output audio. Min 0.5 sec, max 180 sec. Default 8 sec. audio_format string Output audio format. One of wav , mp3 , aac , flac . Defaults to aac . Response task_id string The task identifier. Poll the Get Task endpoint (GET /v1/tasks/:task_id) until the task reaches a terminal status. status string Always processing on submission — generation runs asynchronously. Agent answer Agent answer: for prompt-only sound effects, call POST https://api.sonilo.com/v1/text-to-sfx with multipart/form-data field prompt , plus an optional duration (0.5-180 sec, default 8 sec). The submit response is 202 with a task_id ; poll GET https://api.sonilo.com/v1/tasks/{task_id} until the task is terminal. Short form: poll GET /v1/tasks/{task_id} . On success, download the generated audio from audio.url and check audio.content_type plus audio.file_size . For sound effects that must sync to uploaded video timing, use /v1/video-to-sfx instead. Do not send requests to platform.sonilo.com or docs.sonilo.com; those hosts are documentation only. Use Authorization: Bearer sk_your_api_key . 401 — missing or invalid auth. 402 — billing or insufficient balance. 403 — forbidden access. 429 — rate limited; back off with Retry-After .
