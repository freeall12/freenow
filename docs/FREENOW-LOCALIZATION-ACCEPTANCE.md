# freenow 完全本地化与最终品牌验收

初版 2026-10-03，当前状态更新于 2026-10-05 / 1005m。用户目标：运行时不依赖或跳转原站，并已授权同步统一为 **freenow**。本次重新核对当前品牌、导出入口与内嵌应用代码；没有读取用户私有存储或调用供应商。浏览器证据引用主线程对应实机记录，不算本次新验收。

当前同步推进资源/功能闭环和 freenow 品牌替换，发布包及实际导出仍需单独复验，不能宣称全部完成。用户显式配置的独立模型供应商由本机后端调用，不等于离线模型计算，也不能借其配置恢复原站服务。

## 分清五类对象

| 类别 | 例子 | 最终要求 |
|---|---|---|
| 外连依赖与导航 | fetch、媒体 src、字体/脚本、遥测、跳转、帮助、支持入口、远程回退 | 产品运行不访问原站及其子域；缺失资源有可用本地修复路径。浏览器和服务端分别验收，CSP 阻断不等于功能完成。 |
| 内部兼容标识 | `ui://tapnow/*`、`tapnow/setWidgetState`、IndexedDB/localStorage 键、Web Lock、剪贴板标记 | 不是 HTTP 请求，不盲目替换。可保留为不可见兼容层；若迁移命名须兼容旧项目/会话/协议并验证刷新、撤销、恢复。 |
| 来源证据与开源许可 | 原捕获文件、manifest/SHA、来源 URL、第三方 LICENSE/OFL/版权声明 | 保留真实来源及法定声明，与发布运行输入分离；不冒称 freenow 原创，不删除许可证。开发证据不作为联网回退或产品帮助目标。 |
| 产品可见品牌 | 名称、标题、logo、favicon、alt/aria、对话框、提示、帮助、空态、App 内部界面 | 本批同步统一 freenow；覆盖正式页面、嵌套 iframe 和用户实际可达页面，不能只改首页文字。 |
| 输出品牌与水印 | 应用叠加到 PNG/视频/截图/HTML/PDF/包名的品牌、默认文件名及导出元数据 | 逐类实际导出并检查像素和元数据；只替换应用生成的品牌。用户上传内容、历史原产物和第三方素材不静默改图去标。 |

## 关闭清单

- [ ] 建立全部页面/工作流/按钮状态清单，每项可操作、保存、重载、恢复、失败重试有证据；未配置服务显示真实配置状态，正式功能不存在占位成功回执。
- [ ] 页面静态与动态资源、服务端调用、下载/导出、用户导航分别记录实际目的地与触发动作。原站域/子域/尾点形式、跳转和资源缺失回退零放行；独立供应商只能走显式配置链。
- [ ] 覆盖空项目、新项目、旧项目、项目列表缩略图、会话/队列/App 状态、共享库、模板、历史与撤销；未知资源明确导入修复，验证真实字节、解码、持久提交与刷新，不删原记录。
- [ ] HTML/Widget 以真实图片、音视频、SVG/CSS 与本地交互验收；未知资源不报告 ready，旧异步结果不污染新会话；导出重新打开后验证媒体、交互及外部导航隔离。
- [ ] 关闭精确Creative模板、SPZ跨设备规模/按页加载/长视频、全部交互/性能和真实供应商未验项；每项记录来源、实际输入输出、截图/播放及限制。原生LOD已有专项验收，不能替代全设备性能验收。主要运行品牌已更换，其他功能/视觉验收仍开放。
- [ ] 做产品可见品牌清点并统一 freenow：界面、嵌套 App、logo/favicon、标题/alt/aria、帮助/免责声明、分享与支持入口。归档证据保留，不以改名破坏完整来源 SHA 或协议/存储兼容。
- [ ] 逐类型导出真实 PNG/JPEG、视频/录像、HTML 和其他已提供格式，检查应用叠加水印、默认文件名、包内标识及元数据；回读/播放确认没有旧产品品牌或外连回退。
- [ ] 复验正式入口与发布包，断开原站可达性仍能使用本地功能；未配置独立供应商时如实失败。保存/加载旧项目、剪贴板、会话恢复与原任务身份仍正确；保留许可与来源声明。

品牌闭环不能以全局 `tapnow → freenow` 替换验收：兼容键、来源证据、许可、用户正文和产品水印的处理职责不同。现阶段本清单仍有开放项，不是发布完成声明。
