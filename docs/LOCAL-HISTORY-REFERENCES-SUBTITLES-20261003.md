# 本地历史、参考校验、学习卡与字幕 · 2026-10-03

本批继续补齐已采集官方行为及独立本地运行链。没有调用真实生成模型、没有新增依赖，也没有开始最终品牌替换。所有合成媒体只用于验证读取、解码和应用机制，不代表模型质量或取得了缺失的官方素材。

## 视频历史与输入准备

视频历史现在对每个版本使用自身画幅、对本地封面与预览失败回退统一解析资源，关闭时尊重上层弹窗、菜单、输入法与焦点。独立审核另修复低清预览污染原视频元数据、错误提示冒泡误设主图。真实浏览器已验证 4 秒横/竖/方视频解码播放，原生 Escape 逐层关闭、切批释放播放器、延迟解析不复活已关闭界面，以及竖版主图保存和刷新恢复。见 [具体证据](VIDEO-HISTORY-RUNTIME-20261003.md)。

参考时长使用统一规则：下界严格，上界及总上界使用目录容差，真实解码后才确认未知时长。空全能参考只在媒体和主体元素都不存在时投影为文生视频，保留实际主体字段。真实浏览器的 9 个场景通过；1.9 秒、30.25 秒、15.15+15.15 秒均在传输和适配器调用前拒绝。见 [时长及模式验收](VIDEO-REFERENCE-VALIDATION-20261003.md)。

## 本地预览与服务边界

旧互动学习卡的目标图、学习者结果和对照图支持精确索引迁移。整张卡所有槽位均可验证时才发布，读取本机真实字节、核验 SHA/类型/尺寸并完整校验学习板；有未知资源就保留整卡待导入。真实浏览器验证已知三槽均解码为 200×200、官方学习板显示、刷新保留；未知卡未向 iframe 传递远程地址。独立审核确认精确字段证明、CAS 重算和新草稿保护，见 [学习预览迁移](INTERACTIVE-LEARNING-PREVIEW-MIGRATION.md)。

服务端还在输入准备前检查明确媒体字段，防止直接 HTTP 请求把原站媒体地址转交独立供应商。提示词和普通文字不做全字符串扫描；原站资源缺失不能靠供应商回源补齐。见 [隔离合同与检查限制](GENERATION-MEDIA-INPUT-ISOLATION.md)。

## 音频字幕

供应商可在每个真实音频输出上附 `subtitle:{text}`，正常媒体归档与任务恢复保留该有界元数据；合法空字幕省略，不能从提示词或普通文字输出伪造字幕。见 [服务端合同](GENERATION-AUDIO-SUBTITLE-CONTRACT-20261003.md)。

画布新增同步字幕事务：精确位于来源音频右侧 `width+80`、同一世界 Y 坐标，保持选区，一次撤销同时移除新文字与连线。既有字幕更新校验对象及原正文，正在编辑而未保存的字幕草稿阻止结果覆盖；同内容不增加撤销。显式恢复新结果在保存前同步捕获实际音频绑定，已有恢复结果没有原绑定收据时不盲目重绑定。

真实浏览器已经验证：正式请求构造与 TaskService/application 应用 2 秒 WAV，实际播放进度增长；音频 `(500,140)`、宽 300，对应字幕 `(880,140)`，真实来源 ID、首尾空格及换行保持。原位更新只更新同一字幕节点；显式阻断一次确认保存后重试成功，没有新增节点、撤销或供应商调用。单步撤销/重做字幕、保存回读及刷新同一音频 asset 和字幕恢复通过。详见 [字幕前端验收](AUDIO-SUBTITLES-20261003.md)。这是独立合同回放，不是 LLM 或 Seed 服务联调；刷新任务恢复的新导入分支仅有代码与定向检查，未做该分支的 Computer Use。

服务已重启加载后端变更；实际本机 `POST /api/generation/tasks` 对 `http:tapnow.media/local-isolation-probe.png` 返回 HTTP 400 / `original_service_blocked`。专用隔离测试与独立原始反例通过。额外相关检查存在 6 个旧素材归档/取消检查失败；撤去本批调用的单次对照仍是同样 6 例，未修无关 fixture，未声明全套通过。
