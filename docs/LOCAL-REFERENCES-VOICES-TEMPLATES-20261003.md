# 文本引用、音色目录与模板来源本地接线

本批补齐真实文本引用编辑、共享音色目录/试听和本地模板来源校验，并关闭 Agent Markdown 指向原站的导航入口。功能与最终品牌验收仍未完成；本批没有提前替换品牌。

## 行为变化

- 文本生成提示词使用现有 Tiptap 原子引用，按稳定节点 ID 绑定，支持画布选择、排序、删除、来源更新、复制重映射与单步撤销。普通输入与引用调整复用编辑 DOM，避免重建造成焦点丢失；节点世界坐标保持不变。实现位于 `canvas-text.js`、`text-generation-ui.js`、`app.js`。
- 音频节点和 Agent 共用本机音色目录，支持搜索、分页、真实音频试听、稳定 voice ID 与关闭取消。服务端 `server/voice-catalog.cjs` 使用配置的 ElevenLabs 目录，Key 和上游预览地址不暴露到前端；无配置明确返回 503，不能用测试音色冒充供应商。配置见 [VOICE-CATALOG.md](VOICE-CATALOG.md)。
- 真实模板选择交接可关联本地 HTML。原始字节必须与登记 SHA256 一致；只读源与可编辑作品原子保存，重导入保留最新编辑。Agent 读取时检查当前会话和最新选择，保存失败不伪报成功。自由 HTML 创作不依赖原模板取得。实现与缺口见 [模板来源合同](AGENT-TEMPLATE-SOURCE-20261003.md)。
- Agent Markdown 的普通链接、图片链接与自动链接复用来源策略；原站地址只保留文字，独立链接及 mailto 保留。已重建 `assets/agent-editor.js`。

## 本批实际验证

只执行相关专项，不重跑全套。

- Computer Use 在独立合成文本画布执行 21/21 检查：画布选择、Escape 回焦点、真实连边、原子引用、排序、撤销、更新来源、语音迟到保护、删除、坐标尺寸、IndexedDB 整页重开与 Backspace。初次失败为 QA 状态断言和全局撤销清空选择的假设，按真实产品合同修正。QA 配额问题通过加载数据前不写 localStorage 解决，没有清除用户数据。生产图事务专项另有 3 项通过。
- 本机音色合同 fixture：目录和 WAV 试听 200，原生播放器实际播放两秒并结束；节点/Agent 分别把所选 440/660 fixture ID 写入真实请求参数。再次试听后 Escape 关闭菜单，实际触发音频释放并把焦点交回入口。4173 生产路由无 Key 返回 `voice_catalog_configuration_required` / 503。目录后端专项 11 项、前端及生命周期专项 19 项通过。真实供应商尚未验收。
- 模板实际 picker 搜索字符花房并确认后，保存真实 handoff，显示正文缺失。错误 HTML 显示 SHA256 不匹配且没有写入作品。自由 HTML 保存为 revision 1，刷新后作品和 handoff 保留。QA 会话改用独立 IndexedDB，未写或清除用户 localStorage，未改产品数据库 schema。
- 模板上下文独立复核 3 项通过，关闭了末次读取时选择变化与失败回执被刷新覆盖的问题；专属源保存/控件及存储专项通过。所有正向原模板导入自动测试使用明确合成摘要，不代表取得官方正文。
- Markdown 原站隔离专项 2 项、Agent 构建和变更差异检查通过。主画布刷新后真实 Agent 面板可打开，原草稿仍在。
