## 三维点选

将只识别 Mesh 的 CPU Raycaster 换为真实 GPU ID 像素拾取，保留 Mesh/Line/Points 的原材质 alpha、alphaTest、蒙皮和 morph。相机辅助映射与运镜关键点优先沿用现有逻辑；ID pass 在等待读回前恢复原材质和 renderer 状态，关闭等待在途读回再释放。导航、目标/项目变化、撤销及显式播放操作使旧命中失效，正常连续播放允许选择点击帧对象并停止动画。

真实 GPU 发现并修正了单像素视锥裁掉点精灵及 DPR 乘算的问题。最终保留 1×1 framebuffer，使用完整投影及平移的物理 viewport，不增加全画幅 ID 缓冲。这是为实现功能契约的本地修正，不声称逐字复制官方算法。

Computer Use 已确认透明实体/孔、alpha 0.049/0.05/0.051、alphaMap 通道与 MASK、线与虚线空档、点精灵透明角、morph/skin 六个位置、相机机身/遮挡，以及播放中点选停止。DPR 2 细线 QA 做了明确的测试几何像素对齐，生产线宽不变。13 项专属与21项相关检查通过；独立复核发现的问题均修复。详细条件、截图和未验范围见[GPU 点选记录](STUDIO-V2-PICKING-GAP-20261003.md)。

## 普通音频上传

打开原生文件选择器时固定节点对象、项目、内容快照和选择序号；在解码、素材写入之后重新核对。后选文件、取消新选择、切项目、删除/重建同 ID 或变更来源不会被迟到结果覆盖。保留文件名与300×300普通上传行为，同步秒/毫秒时长，写入 imported 来源；保存失败保留已应用内容并使用现有画布保存入口重试。

实机先挂起真实2秒WAV解码，后选3秒WAV保存，随后释放旧结果：节点、asset、undoCount均保持新结果。实际播放从0.417875秒至3秒/ended，刷新后同asset、新Blob和decoded波形保持。另两个节点及连线不变。4项定向检查和独立异步写入复核通过；见[上传保护与证据](AUDIO-UPLOAD-GUARD.md)。
