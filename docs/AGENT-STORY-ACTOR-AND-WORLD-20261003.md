# Agent 创作页面与世界资源准备 · 2026-10-03

本批在既有框架与官方模板上增加三个实际工作流：表演节奏、剧本结构板、人物情绪。加上既有三个选择器及导演批注，现有7个已接入的版本URI；这不代表全站或全部22种工作流完成。

## 可使用的本地行为

- 表演节奏：真实固定时长、驱动力曲线、六类节拍、表演备注与对白时长检查请求。确认须与已经提交的状态及官方PS1全文一致，保留来源场景进入正常Agent队列。
- 剧本结构板：官方轨道/分幕场景卡、因果提示、筛选、收起、排序、新建场名及废弃方案；NS1确认核对已保存顺序，新场景不会被冒充为已有正文，画布写入仍走原修改流程。
- 人物情绪：原始内嵌3D灰模、情绪方向和图像/视频状态。实际节点派生人物预览，原始来源随show_app结果持久保存。仅该页面允许调用`actor_emotion_save_expression_guide`，实际解码512×512 PNG/WebP、存储素材并创建真实画布节点后才返回guide引用与SHA256。图片保存不调用生成模型；AE2确认仍进入正常Agent回合。
- 新应用首次默认状态实际持久化，后续状态写入串行。确认等待最新提交；保存失败、来源/图片变化、页面重载或会话切换拒绝陈旧回执。重新加载可重试失败的状态保存，不覆盖新的排队编辑。
- 相同人物表情的重复确认复用实际引导图节点与稳定交接ID。已经创建的节点即使随后会话保存失败也保留真实可见状态，不伪称整图回滚。

## 画布响应优化

`CanvasApp.setRightPanel` 在打开、关闭和调宽侧栏时走现有视口刷新，复用布局与堆叠索引；排队中的节点拖动仍升级为完整刷新。

一个生产函数探针验证60节点初始化加三次调宽：布局调用240→60、堆叠索引4→1；浮层通知不缺失、坐标与选区不变，53×29屏幕像素拖动按0.7缩放精确转换。该结果是调用计数，不是整页帧率或耗时基准。

主画布隔离页实机发现并修复启动顺序竞态：agent-client在local-assets.js之前加载，缓存动态模块可能提前完成。人物runtime现按实际调用读取存储，避免初始化时捕获undefined而连带阻断所有应用。重载主画布后不再出现应用模块失败，AI侧栏与节点浮层正常显示。

侧栏宽度改为现有CanvasStore中的`agent-panel-width`记录，合并连续写入并保留冲突检查；旧localStorage只作迁移和尽力同步，容量满不再阻断已成功的IndexedDB保存。浏览器实际拖动480→556，收起重开与刷新后均恢复556，无保存失败提示。未清理用户存储。

原生生成QA默认每次加载使用随机数据库，因此不能用默认模式证明刷新恢复。本批增加明确的`persistSession`隔离开关；验收入口`/qa/native-creation-app.html?session=panel-20261003&persistSession`使用固定测试命名空间，正常默认模式仍保持随机隔离。截图`/tmp/freenow-agent-panel-width-20261003.png`记录刷新后的实际结果。
