# freenow Desktop 0.1.0-alpha.1

**草稿验收中：** 文件和ZIP已核验；原生安装包窗口与重启恢复尚待Computer Use完成。

首个 macOS Apple Silicon（ARM64）桌面开发预发布。Electron 44.6.0 内置 Chromium / Node，独立运行无限画布、媒体编辑器、3D 片场与创作 Agent，无需另外安装系统 Node.js。

## 下载与配置

- 解压 `freenow-0.1.0-alpha.1-mac-arm64.zip`，打开 `freenow.app`。SHA-256 见 `SHA256SUMS.txt`。
- 未使用 Developer ID 签名、未公证。Electron 可执行文件保留其 ad-hoc 标记，不能等同于开发者签名。macOS 可能要求来源确认；本发布不提供关闭系统保护的操作。
- 桌面固定本机入口 `127.0.0.1:4183`，用户数据在 `~/Library/Application Support/freenow-desktop/`。浏览器源码项目不会自动迁入。
- 模型配置：应用菜单「freenow → 模型接口配置…」，编辑独立 `providers.env`，退出重开。Key 仅由本机后台读取，不在发布包中。
- FFmpeg / FFprobe **不附带**；涉及裁切、封装和部分媒体处理时需外部安装，可配置 `FFMPEG_PATH` / `FFPROBE_PATH`。

## 本批实现

- 桌面窗口、沙箱与独立本机后台、固定origin、单实例、用户数据隔离、关闭/刷新前等待 Agent、片场与画布保存；后台关闭期间冻结输入，存储失败独立收尾且默认保留画布。
- Agent 调色最后参数保存、事务等待、失败重试和同一PNG上下文交接。
- Sonilo 原生 SFX 文生音效、完整视频音效、连续小数分段、0.5秒Agent指令、实际WAV转换与本地结果归档。
- README 中英文、实际截图、功能/适配器目录、验收索引、llms.txt与仓库主题。

## 边界

- Alpha 开发版本，整体一比一复刻仍未完成。92份精确创意模板、Enhancor原生接入、部分Ark媒体上传与模型差异、全站逐态视觉/交互、长期存储和复杂高斯场景验收仍开放。
- 不是“填一个Key就全部可用”：各能力需要相应供应商、模型权限和配置；自定义任务网关须另外实现对应合同。
- 未使用真实Key或执行付费推理。SFX验证使用本机固定正弦波，不能证明真实供应商音质。
- 本地运行不使用TapNow服务或账号，配置供应商后提示词与所需媒体会发送给该独立供应商。
- 仅 macOS ARM64 ZIP，手动更新；本版本没有自动更新、Intel、Windows或Linux发布。
- 仓库没有覆盖所有资源的统一开源许可证。第三方库许可独立保留；参考模板与部分字体再分发证据尚不完整，不能将整个包视为MIT授权。见来源说明。
