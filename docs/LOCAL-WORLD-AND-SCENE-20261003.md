# 本地世界接口、片场动画和 Agent 建议 · 2026-10-03

本批增加实际本地行为，不代表全站一比一验收完成。运行时未增加 TapNow 服务、账号、资源或动态建议请求；新增供应商配置只指向用户自行配置的生成服务。

## 实现

- Marble 原生协议加入生产 gateway/router 与前端配置识别。精确 alias、输入模式、原 operation 恢复、下载校验和本机资源归档共用现有生成任务链。配置见 [原生接口](MARBLE-NATIVE-SETUP.md) 和 `.env.example`。
- 世界节点、资源加载和 Agent 共用纯渲染能力接口。当前支持 GLB 网格；SPZ 尚无本地渲染器，因此按钮、快捷键和 Agent 都在提交前明确拦截，配置就绪不等于可预览。
- 3D 多场景导入分别绑定共享对象的动画，过滤无关轨道，保留缓动和无名对象动画；默认模型加载和未选场景释放保持当前场景共享资源；重复导入同一导出模型会分配独立 Studio ID，同时保留 UUID 动画和镜头关联。见 [片场说明](STUDIO-V2-MULTI-SCENE-IMPORT-20261003.md)。
- Agent 建议改为本地完整指令，Brainstorm 写入既有应用引用节点，点击不自动发送；轮换后焦点回到按钮。保留 30 条来源数据，界面仅展示 18 条创作/记忆/Skill 建议，排除 12 条型号推广；使用现有 Tabler 图标和本地 Brainstorm 资源。见 [来源与差异](AGENT-WELCOME-SUGGESTIONS-20261003.md)。

## 本次实际验证

只运行相关检查，没有重复全套测试。供应商原生 21 项、生产集成 7 项、渲染预检及相关世界资源/Agent 26 项、欢迎建议 6 项通过；片场实际 loader/Mixer/资源生命周期与导入回归详见片场说明。交叉审核发现并修复无名共享节点、异步场景完成顺序下缓动丢失。

Computer Use 使用隔离入口 `/qa/native-creation-app.html?session=multiscene-20261003&persistSession`，通过产品控件操作，无注入业务状态：

1. 上传本地多场景 glTF，选择默认第二场景，实际显示红色模型；仅一个镜头/一段相关运镜。播放、放大镜头预览并将进度拖到 1.00/2.00 秒，返回画布后刷新，重入仍为一段运镜且可播放。
2. 世界模型切到 Marble，生成按钮明确禁用；填入提示词并按 Cmd+Enter，仍明确提示渲染未接，检查器 POST=0、job=[]。
3. 点击 Brainstorm 建议后，输入框为完整指令及不可编辑应用标签。刷新重开后标签和全文保留；未发送。清空测试草稿、换三组到记忆建议，焦点留在刷新按钮；再点普通建议得到完整正文，没有残留应用标签。浏览器错误/警告列表为空。
