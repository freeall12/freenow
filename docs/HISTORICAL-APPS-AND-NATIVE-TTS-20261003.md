# 历史 Agent 应用与原生语音（2026-10-03）

本批继续推进完全本地化。功能仍在逐项验收，最终 freenow 标识替换尚未执行，不能将版本登记数作为全部功能完成证明。

## 历史应用

- `animatic@v1` 保留独立输入合同，通过真实本地图片生成预览；播放器按镜头时长裁切及虚拟运镜，总览、选镜、已保存状态和精确 AN1 交接走现有持久队列。
- `character-blocking@v1` 使用真实文本人物板，坐标、目标、比例和 CB1 交接独立于 v3；不注入头像或生成权限。
- 生产 registry/controller/client/schema 已接两版本。对当前 manifest 逐项执行 `getApp`：22 个版本、22 个登记、缺失 0；仍为 20 个功能族。两历史应用均拒绝生成工具调用。
- 修复资源 proxy 将仅适用于 v2 的 animatic 错误展示改写错误施加到 v1 的问题；原 HTML 字节保留。宿主允许 v1 的有界真实故事板数据。
- 来源、项目、trace、保存状态与异步生命周期均校验；晚返回图片响应在取消后释放。历史 QA 恢复原始输入，避免将派生的 base64 图像写回参数框。

## 浏览器操作证据

使用 Codex Computer Use 对本地生产 controller/host 与保留的模板操作，不把本地页面当作官方设计来源。

- 人物站位：目标 video、比例 9:16、Lin 坐标 410/350，确认产生一个 CB1 交接，刷新恢复坐标及原队列。拖动因工具不支持该 iframe 坐标操作而未验收，不能以数字输入覆盖拖动结论。
- 动态分镜：实际 3 镜/7 秒本地故事板，从 SH1 播放到 SH3；总览选择 SH2，显示推进/3 秒与对应裁切图；确认生成 `AN1 v=1;a=confirm;sheets=1;shots=3;dur=7.0`，刷新仍为原单条交接及 SH2 状态。
- ElevenLabs：独立 loopback 监听器提供当前真实主页面。通过生产音色菜单绑定 `qa_native_voice`，点击生产“生成音频”；生产 router/gateway 完成后返回本机媒体路径并写入真实 `asset:` 结果节点。
- 上游审计仅 1 次 POST，模型 `eleven_v3`、稳定度 0.5、格式 `mp3_44100_128`、4223 字节。原生 audio 解码 0.2 秒，播放到 `ended=true`、`readyState=4`、无媒体错误。
- 语音为明确标记的正弦合同 fixture，不是真实供应商语音。没有真实 Key，也没有付费生成；这只证明实际前后端与归档/播放链路。

## 语音接口与聚焦验证

新 `elevenlabs-native` 接口直接调用供应商 TTS，按真实 voice_id 发起一次请求。严格验证 MP3 各帧采样率/码率或 WAV 参数，完整字节落本机媒体 store；重启不重发未知请求。没有 Key 时明确未配置。配置见 [ElevenLabs 原生合同](ELEVENLABS-NATIVE-TTS.md) 和 `.env.example` 的注释示例，需合并现有生成路由。

只运行涉及改动的验证：原生 ElevenLabs 14 项、连同音色目录 25 项；历史宿主 3 项；真实 loader 与 v2 兼容 6 项；历史 raw-input 恢复 3 项；独立历史输入/状态/来源及工具 schema 检查。聚焦检查由实现者与交叉审阅者执行，主 Agent 查看共享接线并做上述浏览器操作；未重新运行全量套件。

之前 OpenAI speech 基线失败来自旧 fixture 缺少生产媒体 materializer。本批修正测试使用实际磁盘 store/materializer，普通/streaming WAV、未知状态重启与只补归档共 12 项通过，无需改动该生产模块。

## 原站脱离补强

主页面既有 CSP 已限制 connect/img/media 为同源资源，并非本轮发现了已经成功的原站网络请求。本轮针对控件在 CSP 拦截之前仍消费旧 URL 的路径补强：保留旧快照和撤销记录中的来源，在节点、缩略图和媒体消费处过滤原站地址；待导入媒体明确显示占位。可用的本地主媒体不应被失效的原站缩略图阻断。

搜索结果、搜索域筛选及 Agent 应用/技能详情链接共用原站地址规则。因为 CSP 不阻止用户点击新窗口链接，这部分另行去掉原站导航能力，独立来源链接继续可用。`ui://tapnow` 协议标识及旧存储 namespace 不等于网络依赖，后续品牌迁移需保留旧数据兼容。

原站脱离定向回归：画布/缩略图/主媒体混合来源/下载复制 9 项，候选引用/预览/视频/LocalAssets 消费 7 项，动态链接 12 项；相关迁移和项目检查 42 项、剪贴板和菜单检查 13 项通过。新增媒体隔离证据为真实消费函数的 VM 回归，没有将其描述成全站浏览器抓包结果。主入口重启后实际打开 Agent→全部应用→管理应用→Casting Room 详情，Esc 返回附件按钮，原草稿仍在、无页面错误。未请求真实模型。

交叉复核关闭两个关联回归：图片编辑器必须接收 live node 原对象，过滤后的普通预览 descriptor 不再传入编辑器；真实 preview 入口身份专项 1 项通过。提示词原子引用的缩略图读取失败或返回原站时改为成熟图标占位，保留引用标签和身份，避免未处理 Promise 拒绝；专项 1 项通过，并用现有构建脚本重建 Agent 编辑器 bundle。
