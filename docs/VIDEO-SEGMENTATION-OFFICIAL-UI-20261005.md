# 视频目标识别的官方页面核对 · 2026-10-05 / 1005n

本轮通过 Computer Use 只读操作 [TapNow 官方画布](https://app.tapnow.media/)，本地页面仅用于后续实现验收。未上传素材、确认识别、提交生成或修改原节点内容。官方已有视频及其提示词属于用户内容，未复制到公开仓库或文档截图。

## 实际观察

1. 在节点搜索中筛选「视频」，定位已有视频，选中后出现包含裁切、高清、替换、移除等图标的横向工具栏。
2. 点击橡皮图标打开「物体移除」。页面先显示「正在检查视频…」，随后显示实际视频时长、播放进度、下方目标卡和「添加蒙层」入口。
3. 点击「添加蒙层」后，视频进入带灰色遮罩的框选状态。真实鼠标拖动形成圆角矩形；矩形内视频保持可见，矩形外变暗。右下角有变换把手，矩形下方是白底取消与确认按钮。
4. 取消按钮仅清除矩形，保留物体移除工具；点击画布空白处退出工具。一次真实 Escape 操作未产生可观察的界面变化，不能以此宣称原站具有键盘取消层级。
5. 本次未点击矩形确认按钮或 Generate，所以没有将原站识别耗时、蒙层输出、费用或生成结果列为已实测。
