## 实机发现与修复

首轮平台裁切发现1:1输出801×800、16:9输出1200×676。原因是千分比边缘分别取整，丢失精确比例；现在按官方`ratio_id`取可容纳的最大整数比例矩形，并保持用户取景位置。新卡片已实际输出正确尺寸，旧产物和回执原样保留，不能被算成修复后的验收结果。

调色Apply后的官方`update-model-context`在长耗时处理后可能丢失短暂用户激活；改为成功且仍有效的Apply回执授予一次精确上下文写入许可。新上下文及裁切/拼装回执纳入有界历史投影，标记为历史证据，后续修改仍须读取当前节点。媒体大串与宿主来源快照不进入模型续轮。

独立审阅修复失败媒体流未取消、解码资源泄漏、关闭未中止、旧操作失败补偿覆盖新回执、来源预览被原地替换、撤销后错误复建等问题。图片像素处理分片让出主线程，媒体读取与解码有容量、超时、来源和关闭取消边界；这不是最大尺寸帧率验收。

正式拼装工具只收三个持久标识，审核正文和计划由宿主取回。图和会话保存前后核验真实源/产物字节及节点身份；失败按当前版本撤回会话回执并补偿保存。独立复现会话保存等待期间删结果、替换产物字节或来源字节，均拒绝成功且不重复拼装。服务端旧的“仅支持三个选择器”指令同步改为当前工具schema，服务已重启加载新定义。
