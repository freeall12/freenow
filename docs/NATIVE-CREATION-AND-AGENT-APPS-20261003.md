## 本次实际浏览器操作

- 原生生成隔离页：通过生产提示词与生成入口，H3 参数得到固定本地 MP4，Tripo 得到真实本地 GLB 并在 Three.js 中显示。夹具明确标记固定资源，没有提交供应商请求。
- 导演批注：选中“林岚推开木门”并添加镜头说明，确认后队列恰好一条；刷新保留批注，重复确认不重复入队。使用生产 registry/controller/host 与未经修改的官方 HTML。
- 交叉复审补齐实际事务提交等待后，再次修改该镜头说明并确认，队列新增且仅新增一条；刷新后新说明和两次不同内容的交接均保留。生产存储失败、保存期间切会话/重载由定向回归验证，浏览器未模拟磁盘故障。
- 历史：1200×800 原 PNG 与 300×200 缩图分别提交；原失败收据刷新后重试归档成功，预览及应用回画布保持原图尺寸和来源；修改下次参数后再次预览仍为原模型、提示词和日期。
- 片场：空场景添加球体，随后添加立方体，两次实际保存；更多菜单首项聚焦、Escape 返回更多、光照首条滑杆聚焦、Tab 进入外部控件后关闭均通过。最终重载后再次首次添加球体，焦点回到工具栏“添加模型”。

片场早期点击曾命中 QA 检查器覆盖层，事件记录已确认该遮挡；验收页新增收起按钮后完成以上操作，不把遮挡误记为生产功能故障。

## 定向检查与剩余范围

原生提供方各 16 项、跨 UI/提供方恢复集成 7 项检查通过；GLB 本地化、素材来源、H3 默认值及媒体历史各运行对应回归。片场浮层最终 7 项检查通过，另有真实导入回调检查；历史启动时序与跨时区分组分别有回归。只因修复引入新行为才补验，不重复运行整仓测试。

Agent 应用的保存/排队成功回执现在等待会话事务完成；等待期间暂锁发送，失败定向撤销本次队列项与去重身份，iframe 重载或来源改变后拒绝迟到派发。补偿写入失败保留明确错误，不假称撤销已落盘。相关队列 11 项与后续新增的代次、卡片透传和恢复保护检查通过。

真实供应商质量、实际压缩 GLB、片场缺失资源文件补充流程、其余 Agent Apps 与全部页面的同视口逐态对比仍待完成。配置 Key 和明确模型映射后才可联调已实现的协议；本批固定媒体证据不代表全站已做到“填任何 Key 即全部可用”。
