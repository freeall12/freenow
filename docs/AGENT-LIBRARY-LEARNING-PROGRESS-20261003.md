## 实际功能

- 个人素材选择：读取当前本地素材库、按文件夹/类型/名称查询、保存浏览位置、引用后提问、把实际媒体加入画布。引用接入既有`referenceMention`及媒体输入链，模型收到实际素材输入；`library://`只作为来源身份，不冒充可访问的图片地址。
- 互动学习：官方课程目录与五题学习板、提示阶梯、自评和草稿保存。精确核对IL1与已提交状态，反推点评、改编和进入下一关交给正常Agent队列；点评和生成仍需模型接口，自评不是模型判分。
- 制作进度：仅查询当前会话真实生成回执和任务，不提交、恢复或取消生成。多结果展开为实际目标节点；只有任务成功、画布已应用、媒体来源匹配才展示完成。产物已删除或编辑不能冒充原完成结果。

合同与边界：[素材库](../src/features/agent-apps/LIBRARY-PICKER.md)、[互动学习](../src/features/agent-apps/INTERACTIVE-LEARNING.md)、[制作进度](../src/features/agent-apps/PRODUCTION-PROGRESS.md)。

## 保存与来源保护

专属宿主方法按资源白名单开放，不能从页面调用任意Agent工具。个人库编辑要求实际用户动作；只读制作轮询允许自动查询，官方SDK的`progressToken`按请求ID核对，不错误要求人物图片工具专用的callId。

素材选择同时核对库快照、会话、项目、iframe代次和实际节点。保存期间节点被撤销、删除或改图时拒绝成功回执；已写入会话的回执须实际补偿保存。排队后同ID替换了素材，在媒体读取前后按原来源签名拒绝发送。真实可见节点若已产生而后续保存失败会保留，错误明确，不伪称全图回滚。

## 本地媒体传输

实际浏览器暴露了宿主Blob地址不能被双层opaque iframe读取的问题：只有完成计数变化，卡片仍缺图。已改为真实媒体字节的有界data URI；新增仅允许`production-progress@v1`的本地transport proxy，保留官方归档proxy与所有官方应用HTML。该副本仅加入内联媒体来源，不开放网络或`allow-same-origin`。

单媒体读取最多8MiB、一次查询读取总量16MiB、显示预算15MiB，宿主16MiB回执限制只用于此制作查询。30秒超时、iframe失效和关闭会取消实际流读取；相同来源预览复用缓存。视频超出显示预算时只回退到明确标注的真实首帧；无法获取受限预览时明确标注未加载播放，不改原任务状态，也不假装视频已可播放。
