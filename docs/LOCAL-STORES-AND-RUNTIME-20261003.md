# 共享素材迁移与本地运行隔离 · 2026-10-03

本批继续将官方站点限制为开发参考来源。功能与视觉验收尚未全部完成，因此没有提前执行统一 freenow 品牌替换，也没有修改用户媒体或原始参考文件。

## 实现

- 素材库、个人模板、主体库、生成历史均有显式本地迁移入口。按完整来源 URL 哈希匹配已经核验的本机文件；未知引用保留，并显示待导入位置。没有从原站静默下载或删除旧记录。
- 素材库使用原 localStorage 权威记录及共同 Web Lock，模板使用单次 IndexedDB 事务比较原记录，主体库保留原权威记录/CAS，生成历史沿既有操作队列保存。迁移不能覆盖执行期间的新编辑或新任务。
- 生成历史和 Agent 保存主体所需的静态文件，必须经精确索引、长度、SHA-256、MIME 和有界读取校验，才写成 `asset:`。迁移不把失败任务改为成功，也不重新提交生成请求。
- 独立复审发现并修复同一任务混合素材迁移时整组清掉内存源的问题：现在只更新已经迁移的具体媒体字段，其他尚未持久归档的真实源仍可重试，已迁移字段不会在重试时回退到旧地址。
- Agent、压缩、委派、检索、语音、HTML 生成和视频分割补统一服务端目的地址保护：拒绝原站域与重定向，关闭 SDK 自动重试；阻断普通、URL 编码和跨文字流分片的凭据回显。
- 主 `/` 与 `/index.html` 开启本源资源 CSP。生成、Agent、语音等请求已经由本机服务承接，新生成媒体先落盘；主页面不再直接加载外部脚本、字体、图片、音视频或发跨源请求。已保存的旧地址保留，但需要导入本机后才能显示和使用。
- Widget 宿主导航拒绝原站服务域，保留用户主动打开独立资料链接的能力。域名判断不修改来源文案或本地协议标识。
- 修复评论气泡在画布左侧覆盖工具栏、导致素材库点击落入评论编辑器的问题。仅调整现有工具栏层级，坐标和图标不变。
- 修复 Previs 临时 GET 失败后缓存 rejected Promise、相同状态无法再次恢复的问题；按 Promise 身份清除失败缓存，保留较新的请求。

## 新鲜验证

- 浏览器实点素材库、主体库、个人模板和生成历史的迁移按钮；当前验收项目这些共享列表为空，结果为零项迁移。这只证明入口、异步反馈和页面交互，不作为真实用户远程媒体迁移成功的证据。
- 同一页面先复现评论遮挡，再修改后重新加载，素材库按钮可正常打开抽屉，评论没有被误触发。
- 服务重启后实际读取主页面 GET/HEAD 策略；新定向路由检查覆盖 `/`、`/index.html`、路径别名及 Three blob worker/本地运行要求。
- 主画布重载、Agent 编辑器及两个片场入口可打开/返回，无 console warn/error。当前场景为空态，不作为复杂场景、材质或 SPZ 渲染验收。
- 模板目录十张图片全部完成解码，`currentSrc` 全部为同源；实际查看截图 `/tmp/freenow-local-runtime-20261003.png`。页面仍保留当前品牌，统一替换尚未执行。
- 只运行本批迁移、读取边界及接线的定向检查，未重复全量测试。出站独立复核使用真实 OpenAI SDK 和本机 HTTP/SSE fixture，验证重定向与原文/编码分片凭据回显；没有使用真实 Key 或调用生成供应商。
- Previs 独立最小复现确认首次查询失败后第二次查询成功，查询次数为 2，未进行新的生成 POST。
- 素材库实现者额外执行旧 `sidebar-dismissal` 检查时，两项主体编辑器案例因 fixture 删除模块 import 且未注入 `readySubjects` 而失败，不计为通过。静态核对确认 HEAD 已有该 import，本批没有修改 `subject-library/editor.mjs`；没有为此重复全套或改变生产编辑器。

更详细的模块范围及检查见 [资源映射](LOCAL-RESOURCE-MIGRATION.md)、[素材库/模板](LIBRARY-TEMPLATE-RESOURCE-MIGRATION-20261003.md)、[主体库](SUBJECT-RESOURCE-MIGRATION.md)、[生成历史](../src/features/generation-history/README.md)、[服务端出站](server-outbound-policy.md)。

## 保留边界

1. 缺少精确映射的旧媒体仍需本地文件导入修复。主页面也会阻止旧独立供应商的直接远程媒体读取，不能声称该旧直读流程完全兼容。
2. Agent 会话附件、历史 Widget/HTML 内部资源尚未完成类型化迁移；HTML 下载目前仍导出保存的原正文，另开文件不继承预览隔离策略，仍需单独本地化导出实现。
3. SPZ/world 历史整组保留原始元数据并报告待专用支持，未伪装成可用 GLB；实际高斯场景渲染、精确创意模板后续编辑链与全站视觉验收仍未完成。
4. 原生供应商检索工具的内部访问由配置供应商执行，本机出站策略不能证明供应商内部检索的域范围。
5. 未配置真实 Key；局部单元检查、本机固定响应和静态图片解码不代表真实生成质量或全部功能已经一比一完成。

后续完成上述功能与资源闭环，再统一替换界面名称、logo、favicon、产品水印和导出品牌为 freenow，保留历史项目兼容以及开发参考的真实来源。
