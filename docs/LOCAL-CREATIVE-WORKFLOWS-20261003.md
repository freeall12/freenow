# 本地创作工作流增量 · 2026-10-03

本批接入人物站位、产品素材板、广告创意审核三个工作流。设计依据仍为官方安装包原始 HTML；本机 QA 只验证实现。所有预览由宿主读取真实本地节点字节，状态保存后才接受精确协议交接，后续生成仍走正常 Agent 工具与供应商适配器。

## 实现

- 人物站位 v3：真实本地头像裁切、坐标/朝向/吸附/生成目标/画幅、已保存 CB3 核对；可不提供头像，使用官方姓名展示。合同见 [CHARACTER-BLOCKING](../src/features/agent-apps/CHARACTER-BLOCKING.md)。
- Product Kit v1：真实图片解码、配色/调性/禁令/文案/规格状态、精确 PK1 与来源指纹。原始模板要求 HTTPS 缩略图，因此仅在代理装载时，先校验原文 SHA256 和唯一目标表达式，再将该字段改为有界宿主 data-image。磁盘参考 HTML 不改；这是明确记录的传输兼容修改，不声称运行衍生文档逐字节相同。合同见 [Product Kit](../src/features/agent-apps/product-kit.md)。
- 广告审核 v1：首帧快筛、试拍、成片三阶段，本地图片/完整视频预览、标记/备注和 AR1。宿主追加真实 combo→node_ref/文件哈希，不能让 Agent 按名称猜来源；专用代理仅放行本地内联媒体。
- 共享链在真实保存前后、消息保存后核对来源；状态交错使旧确认失效，已保存队列失效时补偿撤销。不扩大 iframe 工具权限。删除了同一次保存前的重复完整媒体读取。

独立复审发现并修复了审片交接丢失来源映射、取消后的迟到 Response 未释放、非流式无界读取。另修复 show_app 等待依赖时的会话身份竞态。

## 新鲜验证

根线程实际使用 Computer Use：

1. 人物站位：真实 QA 头像可见，切换 video / 9:16，键盘将 X 从300调至310、朝向90°调至96°；确认产生一条带两个人物来源的 CB3，浏览器刷新恢复。模拟保存失败后界面可暂显 X320，但提交报错、队列不增加；刷新恢复已保存 X310。
2. 产品板：通过本地文件选择器导入项目已有摄影机 PNG（856×558），官方缩略图正常显示。暖灰改砂岩、加入精密调性，保存并展开测试规格；未确认规格保留禁止使用状态。确认产生一条带 node_ref 与 SHA256 的 PK1；浏览器刷新恢复同一状态和队列。
3. 主服务重启后正式画布、Agent 和已保存 Creative 卡可加载；检查控制台无 warn/error。没有发模型请求。

截图：`/tmp/freenow-character-blocking-local-20261003.png`、`/tmp/freenow-product-kit-local-20261003.png`。审片子任务实际完成中文首帧 keep1/cull1、英文试拍 win1、日语成片 keep1/rework1/win1 的 AR1；本地视频解码并原生播放，刷新恢复、重复确认去重、运行中拒绝与替换来源拒绝均已验证。参见[广告审核合同](../src/features/agent-apps/AD-REVIEW.md)。

局部检查：人物站位13项，产品板11项，审片12项；共享相关集合37项，独立审查8项。集合存在覆盖重叠，不相加为全套测试。本轮未重新执行全部旧测试。

## 未完成边界

嵌套 iframe 鼠标拖动受 Computer Use 坐标安全检查限制，站位仅键盘调整已验。并非所有语言、布局、hover、菜单组合均已复验。隔离 QA 使用真实持久存储与生产宿主，但队列不启动模型，不证明真实供应商效果。

当前已接16/22版本 URI、16/20功能族。剩余 animatic、ecommerce-photoset、layer-composer、previs，以及独立精确模板正文、SPZ渲染、所有资源本地保存和全站同态验收仍开放。功能完成后再统一替换可见品牌为 freenow，保留旧项目兼容与原始证据。

另外新增私有媒体仓库底层及定向检查，详见[媒体本地化实施方案](GENERATION-MEDIA-LOCALIZATION-PLAN-20261003.md)。它尚未接入生成任务或 HTTP 路由，不改变当前远程输出行为，不能据此宣称全部结果已本地落盘。
