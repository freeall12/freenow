# 本地蒙版编辑、音效与布局性能 · 2026-10-03

本批是持续开发进展，不是全站完成声明。官方网站/安装包仍仅用于参考；运行时使用本机前后端及明确配置的独立供应商。未调用收费 API，合成供应商回包只验证软件链路，不代表模型质量。

## 实施

- `openai-masked-edit-native` 接入擦除、重绘、扩图：使用现有 OpenAI SDK，透明 PNG 生成同尺寸 alpha mask，主图首先上传；重绘支持一张本地参考，固定前缀随图序精确调整，保留用户描述。分别按 operation 路由，Key 留在服务端；动态尺寸需显式启用，拒绝静默缩放。详见 [配置与边界](OPENAI-MASKED-EDIT-NATIVE.md)。
- `elevenlabs-sound-native` 支持 Sound v2 自动/0.5–30 秒、循环与提示词影响度，完整 MP3 校验后归档。保留原 Agent 控件范围。详见 [音效合同](ELEVENLABS-NATIVE-SOUND.md)。
- 修复实际浏览器发现的音频数值丢失：弹层在原生 change 事件之前关闭，造成未保存。现在有效 input 立即保存草稿，保持焦点、同步时长显示及滑条，并拒绝旧节点迟到事件。
- 多选布局一次建立关系索引，保留原顺序、父子/堆叠移动语义。片场面板每次刷新仅取一次动画目录，展开、收起和分页恢复正式控件焦点。
- 单/多供应商工厂、前端预检、原生参考素材准备与 `.env.example` 已接线；tasks-v1 保持原合同。同步请求失去回执时保留 unknown，不冒充可查询任务或重复 POST。
- Product Kit 独立演示页改用现有本地图片的内联数据，不再请求官方演示缩略图。确定性派生脚本与 manifest 保留原件、派生件及图片 SHA；真实工作流仍读取当前节点素材，不使用演示图回退。
