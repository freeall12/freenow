# HTML 作品、Widget 与会话附件本地化

本批完成明确资源槽的本地派生与历史聊天附件迁移，不代表全站一比一复刻完成。运行资源不回退到原站；最终 freenow 品牌替换仍按功能完成之后执行。

## 实现

- 共享 `html-document.mjs` 惰性解析原文，用完整来源 SHA 索引核对本地字节；asset 只读转码，资源嵌入 data URL。原作品、Widget 正文与版本不改写。
- HTML 预览与下载使用同一派生结果，含 opaque iframe 和外层导航限制；未知资源、外部代码及未支持样式给位置诊断并禁用完整导出。异步关闭、版本变化与切换不会下载旧作品。
- Widget 增加可见缺失资源状态、重试、取消与来源绑定缓存；不放宽现有消息、上传或网络权限。
- 主 Agent 聊天记录菜单增加“迁移本地附件”。仅处理实际 uploads 的 asset/可选 image，保留提示词、恢复记录和原始未识别引用；串行保存、CAS 与新草稿保护防止覆盖。暂停队列可迁移，执行中任务和可运行队列拒绝。

## 定向核验与剩余边界

共享 HTML 9 项、artifact 导出 6 项、conversation 新增 9 项、Widget 新增 3 项及相关既有检查由实现者完成；独立复核组合真实图片字节与实际预览下载回调，未发现本次范围剩余已复现问题。根任务仅补语法/diff 检查与上述实际操作，没有重复全套测试。

尚未完成任意历史外部脚本、外部样式/CSS import、动态资源代码的独立本地打包，也未完成未知资源的通用人工绑定界面。本次未验白模完整录像链或真实模型生成质量；无 Key 时不能宣称供应商已验收。SPZ 渲染、全部模板原文与编辑链、完整功能/视觉矩阵以及最终品牌替换仍开放。
