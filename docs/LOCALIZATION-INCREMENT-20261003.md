# 原生视频接口、持久化与媒体来源 · 2026-10-03

## 依据与实现

- 官方 TapNow 现场操作：进入3D片场空场景、展开视角帮助、Escape关闭后焦点返回按钮，再返回画布。帮助含拖动转向、滚轮远近、W/S前后、A/D左右、Q/E升降及Shift加速；这只是该菜单核对，不代表完整片场验收。
- 火山方舟官方文档、公开 Python/Go SDK 交叉确认原生视频提交及查询格式。新增 `ark-native`，保留真实任务ID、只读恢复、首尾帧顺序、媒体引用和样片正式片关系。见 [接口配置](ARK-VIDEO.md)。
- 端到端网关测试发现视频UI准备阶段产生 `undefined` 空字段，持久化合同会拒绝。出口改成合法JSON参数；Ark请求中显式但不支持的规格直接拒绝，不能先替换默认值再生成。
- 会话停止向localStorage完整镜像；分镜操作身份迁移到现有IndexedDB records，旧数据保留，失败不降级派发。见 [存储合同](AGENT-STORAGE.md)。
- 媒体预览不再用编辑器下一次生成的默认模型标记现有媒体。普通生成、批次历史、恢复和分镜保存实际来源；本地导入/裁片没有生成模型时省略该行。

## 未完成边界
