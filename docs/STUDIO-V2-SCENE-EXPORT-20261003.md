# 3D 片场：场景 GLB 导出

## 官方证据与缺口

同版 `reference/studio-v2-page-readable.js:1268–1317` 维护当前文档的导出 Promise/Blob 缓存、单次下载 busy、场景名文件名与文件大小；`1319–1326` 将可用状态、忙碌状态和大小显示在原更多菜单。文档卸载时撤销迟到下载。

修复前，本项目 `ui.mjs` 的更多菜单直接调用 `runtime.export()`，始终下载 `scene.glb`，没有大小、busy 或重复点击保护；`runtime.export()` 缺少加载、项目、原节点、revision 与关闭检查。这是实际导出流程缺口。Draco 解码器与本地 WASM 资源已存在，本轮没有新增压缩解码功能，也没有改动已完成的保存恢复和拾取实现。

## 实现

- 独立 `scene-export.mjs` 在当前版本下预计算真实 Blob 大小。同一场景版本共用 Promise/Blob；点击下载时 busy 单例阻止重复下载。
- 原更多菜单显示“导出场景(glb)文件”及大小；错误允许重试，加载未完成或编辑中时禁用。文件名使用场景名称，默认 Scene 使用画布片场标题；非法文件字符清理后固定 `.glb` 后缀。
- `runtime.export()` 先核验项目和原节点，等待实际场景保存，序列化基础姿态的完整文档与动画副本，再核验 revision、内容对象、会话、编辑状态和关闭状态。变化后拒绝迟到文件。
- 返回画布开始即撤销本次下载资格。关闭若保存失败，编辑与导出仍可重试。此操作不取消或覆盖场景保存。
- GLB 包含模型、用户对象变换、镜头、显式灯光和动画；动画保留基础姿态并能重新播放。网格、选择框、变换助手等不属于导出文档。全局 viewer/grid/lighting 仍沿用现有 `studioV2` 旁记录合同，没有新增保存格式。

## 可点浏览器夹具

`/src/features/studio-v2/qa/scene-export-main.html?session=glb-export-oct03-01`

1. 点击“准备并打开真实GLB布景”，创建明确的合成模型、镜头、灯光与运镜；收起 QA 检查器后查看真实布景。
2. 使用生产“更多 → 导出场景(glb)文件”。大小应出现；文件名应为 `QA GLB 导出城市.glb`。下载照常进行，检查器同时保留实际 Blob，解析 header、对象坐标、镜头、灯光和轨道。
3. 点击“延迟下一次真实GLB结果”，打开更多等待真实编码回包，再点击正式导出。用可见“修改模型本地X=3并保存”改变来源，再释放结果；不应下载旧文件。重试应下载包含新坐标的 GLB。
4. 同样延迟后返回画布，再释放结果；不应产生关闭后的下载。刷新与再次进入仍使用该 session 的独立 IndexedDB。
