# 旧视频本地修复与模型下载隔离

本批继续完全本地化，不是全功能或最终品牌验收。无需新增依赖，没有调用模型服务；保持功能完成后再统一替换 freenow 品牌的顺序。

## 行为

- 旧视频节点提供「导入本地视频」，支持显式 video 及历史 EDITOR_DATA 回退来源。所选视频经真实解码生成首帧，视频与封面分别保存为本地 asset 并核对字节。保留节点坐标、连线、生成参数和历史来源；以单次撤销替换主媒体，重置旧裁剪区间为整段，更新实测尺寸和时长。保存失败仅重试保存，不重复导入。
- WorldNode 下载不再把远程 URL 交给浏览器导航。只允许受限本地静态资源、生成媒体、asset、当前源 Blob 与模型 data URL；解析后再次核对地址，拒绝重定向，有界读取后下载新 Blob。
- 上批播放列表追加的来源竞态已独立复验：等待期间修改源时间线会明确拒绝，目标与撤销记录不变。

## 实际验收

主壳验收页使用正式 app.js、视频播放器、CanvasStore 和 LocalAssets，独立 IndexedDB 与内存偏好，不覆盖用户项目。

1. 通过真实节点按钮与原生文件选择器，导入本机合成红色视频：320×180、8 秒、7144 字节。实际 CanvasStore 回读视频/封面 asset，另一节点与来源日志不变，undoCount 为 1。
2. 刷新后生成新 Blob URL，封面真实解码；播放器 readyState 为 4，播放时间从 0.267 秒走到 8 秒。撤销并保存恢复旧 URL 和 20–24 秒 clip，重做恢复本地视频。
3. EDITOR_DATA 回退节点导入蓝色视频（7118 字节）；刷新后两节点分别保有独立本地视频与封面、实测 8000ms、clip:null，undoCount 为 2。
4. 生产模型下载函数拒绝独立远程地址，读取次数为 0。本地自行车 GLB 实际保存到 Downloads，1,055,520 字节；下载与本机源文件 SHA256 均为 `829c5016658a857aad64056b9aa4a9071ed75cff74e040cdc6e2c9c23200614f`。

截图：`/tmp/freenow-local-video-repair-20261003.png`、`/tmp/freenow-world-local-download-20261003.png`。临时浏览器标签已关闭。视频是已知合成测试素材，不代表模型产物或官方素材恢复；fixture 的 externalAttempts 仅统计其包装的 fetch，不作为全浏览器网络证明。

作者仅运行聚焦回归：视频修复 7 项及新增保存字段保护 1 项；模型下载 4 项及相关 materialization 12 项。主线程额外检查 app.js 语法、diff 格式和真实下载字节，没有重复全量测试。

独立复核确认视频异步守卫、完整替换字段、保存重试及回退接线。模型下载审查发现大写 `DATA:` 被原生 fetch 规范化后误判跳转，修正协议规范化后，以原生 fetch 对大小写 URL 逐字节复验通过；本批范围无剩余已复现缺陷。未据此扩大为所有媒体路径完成。

## 边界

100 MiB 视频预算、浏览器编解码支持和存储配额仍适用。未知素材人工替换不能证明取回了原件；撤销历史保留旧来源，因此迁移提示仍可能列出历史引用。其他媒体槽、精确模板正文、SPZ 渲染、全站交互与大媒体性能仍需继续。当前未执行最终 logo、水印与 freenow 品牌替换。
