# 本机生成配置、Agent 工作流与历史资源迁移

本批继续本地化；不表示完整产品已经达到一比一还原。原站和安装包只保留为设计证据，当前运行功能不使用原站账号或生成服务。品牌统一替换仍在功能完成后的阶段执行，不能通过更名掩盖缺失功能。

## 已接功能

- 动态分镜 `animatic@v2`：真实节点像素、时长/运镜/转场编辑、AN1 精确确认、景别任务及原任务查询。
- 镜头预演 `previs@v3`：实际图板/变体选图、结构化确认、持久待续队列与真实 run_id、缺失图板生成工具、刷新后经原任务 GET 恢复选图纹理。确认与生成工具授权分开，waiting 不伪装完成。
- 电商组图 `ecommerce-photoset@v2`：真实产品素材、逐行计划/参数、提交前确认、每行独立真实任务及标准占位回填。freeform 交给正常 Agent 队列。
- 原版 HTML 保持捕获字节。沙箱加载时用完整 SHA 绑定的派生适配去除这些页面中的 Tapies/固定积分断言，并保留无 Key 的明确“未派发”错误。未知提交仍查询原任务，不重新 POST。
- 浏览器生成配置统一提交本机服务。Key 只存在服务进程内存，旧任务绑定原端点和 Key 版本；切换配置不改变旧任务归属。生成 gateway、native/routed 端点拒绝原站域与重定向。其他服务的全部出站路径仍需继续清点。
- 已知历史资源按完整来源字符串 SHA 索引迁移，覆盖画布、撤销/重做历史、Fabric 图片和片场已识别媒体槽。保留提示词、项目、坐标、视口和未知数据，使用原 CAS 保存；晚到编辑停止 hydrate/自动保存。

配置与迁移合同见 [生成配置](generation-session-configuration.md)、[工作流接线](agent-apps-local-generation-contract.md)、[资源映射](LOCAL-RESOURCE-MIGRATION.md) 和 [画布迁移](CANVAS-RESOURCE-MIGRATION.md)。

## 实际浏览器证据

1. 电商组图导入本机 Sony 相机 PNG，真实解码 616×497，来源 SHA `a67790a705de379fbf7758d6e1136f085deaf50abf5a052d559031e9b6f8b7c3`。编辑主题、保存、刷新后保留。无 Key 时两行返回 `configuration_required`，任务数为零。
2. 生产配置弹窗拒绝原站地址；接受独立本机无 Key tasks-v1 fixture。两行生成经真实 TaskService/gateway 落到两个本机媒体引用。切回环境配置、切至另一 fixture、刷新再查原任务，旧服务 POST 始终为 2，新节点不重复创建。此第一 fixture 输出为 1×1 PNG，只验证传输/身份/持久化，不作为画面质量证据。Escape 关闭配置恢复原入口焦点。
3. Animatic 实际九格输入，SH1 运镜改为推进，确认后真实队列为 1，AN1 中 `SH1:2.0:push_in:smooth:cut`；刷新保留。另一个未确认卡无 Key 操作明确显示“尚未配置图片生成服务……任务尚未派发”，任务仍为零。
4. Previs 时长 3.0→3.1 秒；本机第二 fixture 输出有内容的 96×64 彩色棋盘格，明确为非 AI 测试素材。真实变体 POST 为 1，经 GET 回填九格，选择 ELS 并提交。待续队列为 1，run_id 与已保存提交一致，未执行 Agent。刷新后经原任务 GET 恢复九格，保持 ELS/3.1 秒/同一等待记录，POST 仍为 1。截图 `/tmp/freenow-previs-restored-20261003.png` 已打开检查，包含真实九格及等待状态。
5. 实际现有“交互验收画布”加载成功，无浏览器 warn/error；本机索引返回 167 个来源。已验证 170 对映射、3 对同内容重复，其中 167 对有声明 SHA、3 对仅计算本地哈希。该旧画布未触发需要替换的远程资源；真实用户迁移写入和未知素材导入没有据此宣称通过。

所有验收只用本机服务，没有真实供应商 Key 或付费模型调用。公开仓库不提交本机资源索引、用户素材、任务记录或上述截图。服务最终已恢复 environment/未配置状态；临时 fixture 停止，已有本机媒体保留。
