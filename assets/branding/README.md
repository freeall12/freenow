# freenow 标识

运行界面的新标识为 `freenow-mark.svg`，直接复用已安装的 Tabler Icons 3.47.0 `filled/hexagon-letter-f.svg`。文件未修改路径数据；深色界面通过 `.freenow-brand-mark` 反色显示。许可见同目录 `TABLER-LICENSE`。

来源：https://github.com/tabler/tabler-icons/blob/v3.47.0/icons/filled/hexagon-letter-f.svg

Agent 入口使用同版本 Tabler `outline/robot-face.svg`，以未修改路径的本地文件 `freenow-agent.svg` 提供；画布和片场复用同一资源。来源：https://github.com/tabler/tabler-icons/blob/v3.47.0/icons/outline/robot-face.svg

旧官方素材保留给来源追溯与历史验证夹具，不再用于正式品牌位置。应用品牌更换不修改用户的项目名称、生成内容、第三方作者及资源许可。
